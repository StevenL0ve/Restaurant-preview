# Nest Quest Rentals — marketing site

Single-page static site for https://nestquest-rentals.netlify.app (the
landing page for the [Nest Quest Rentals iOS app](https://apps.apple.com/us/app/nest-quest-rentals/id6749613800)).

No build step. To deploy, drag this folder (`index.html` + `assets/`) onto
the site in the Netlify dashboard (Deploys → drag & drop), or connect this
repo and set the publish directory to `nestquest-website`.

`assets/` contains the web-optimized images. The original full-resolution
source images (1–2 MB PNGs) are not in the repo — keep them wherever you
keep design files, and re-export smaller versions here if they change.
